# Let's Truck Conversion Funnel
## Priority Stack (in order)

```
1. Email List Signup
   └→ Entry point, builds owned audience
   
2. AudioRoad App Download
   └→ Daily engagement, captive audience
   
3. Let's Truck Tribe (letstrucktribe.com)
   └→ Community membership, deeper engagement
   
4. Store Sales (shop/products)
   └→ Monetization, supplements, merchandise
```
